# Agent-generated plaza docs (optional)

Official Inspiration boards from `npm run plaza:agent-showcase`. Each `*.json` has a hydrated `document` with real `image` / `video` / `lottie` srcs. Seed only loads them when media is present (no rectangle mock boards).

**No showcase JSON is checked in.** The Inspiration feed stays empty until you regenerate docs into this folder (or publish from the product).
