# recombyn-billing-sdk

Open helpers for **Billing Protocol** schemas (`UsageEvent`, `PricingVersion`,
hold/charge envelopes).

- Schemas live in `recombyn-protocol` (Apache-2.0).
- This package adds small builders / cost math — **not** wallet DB, margin
  policy, provider keys, or fraud.

See [ADR 0025](../../docs/adr/0025-billing-protocol.md).
