# Landing anti-patterns

- Default template: Hero + 3 cards + 3 cards + Logo strip + CTA
- Three equal feature cards as the first idea (`three_card_layout`)
- Glassmorphism / purple-blue gradient hero with no brief justification
- Invented logos, testimonials, prices, review counts
- Painting a festive poster (`poster_craft`) when the user asked for a website
- Hiding the only CTA, or five competing CTAs
- Cropping a desktop collage and calling it mobile
