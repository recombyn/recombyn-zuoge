# Image gen anti-patterns

- Generating a pretty picture with no thesis / material / light
- Baked titles, slogans, watermarks, or UI chrome in the pixels (unless the user asked for in-image text)
- Purple-blue glass postcard heroes
- Invented logos, prices, or readable fake copy in the image
- Shape-pile “atmosphere” that should have been a bitmap — or a bitmap when a flat vector field was enough
