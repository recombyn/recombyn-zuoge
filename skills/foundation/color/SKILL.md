# Color (craft)

Roles over scattered hex. Token **values** live in `design_system`; this skill owns **how color is used**.

## Hard rules

1. Name roles: primary / secondary / surface / muted / accent. Paint from roles, not one-off hex.
2. ≤1 accent family. Accent area is small (CTA, one mark, one highlight) — not the whole board.
3. Unjustified purple–blue gradient / glass mesh is slop unless Brief asks for it.
4. Contrast: body text vs surface must read. Do not put light gray on white as primary copy.
5. Do not invent a second palette mid-run.

## Roles

```text
surface     page / poster ground
primary     main ink / brand
muted       meta, captions, rules
accent      one job (CTA or mark)
```

## Checklist

- [ ] Roles written into brief palette/tokens
- [ ] Accent is local, not a wash
- [ ] No decorative rainbow
